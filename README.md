# Sistema de Cadastro de Políticos

Projeto desenvolvido para a disciplina de Lógica para Programação.

## Objetivo

Criar um sistema de cadastro de políticos utilizando os principais conceitos da Programação Orientada a Objetos:

- Encapsulamento
- Herança
- Polimorfismo
- Abstração

## Tecnologias

- TypeScript
- Node.js
- npm
- PlantUML
- Visual Studio Code
